# AI as a Management Operating System

An interactive, screen-first workshop for Purdue Master of Engineering Management orientation.

Students do not need laptops. They contribute the business problem, requirements, constraints, and success criteria; the facilitator turns the winning concept into a working prototype live.

## Contents

- `slides.md` — reveal.js Markdown deck (about 75 minutes; can contract to 60 or expand to 90).
- `facilitator-guide.md` — run-of-show, room setup, live-demo staging, and recovery path.
- `content/challenge-menu.md` — the five candidate builds for the breakout vote.
- `content/breakout-worksheet.md` — print one per group.
- `content/live-demo-brief.md` — the on-screen synthesis brief for the winning build.

## Presenting

The deck uses standard reveal.js separators: `---` for a new horizontal slide and `----` for a vertical slide. `index.html` is a local reveal.js viewer that loads `slides.md` dynamically; it does not duplicate or compile the deck content. Serve this folder with any static HTTP server and open `index.html`. Press `S` in reveal.js to open presenter notes.

The workshop is designed around an approximately 75-minute path. Speaker notes contain timing and facilitation prompts, not audience-facing copy.
