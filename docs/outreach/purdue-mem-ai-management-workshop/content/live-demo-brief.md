## Facilitation rules

- Build one useful vertical slice, not an imagined enterprise platform.
- Prefer provided or synthetic demo data; do not enter real student, employer, customer, or confidential information.
- State the approval boundary before the agent begins implementation.
- Keep the build reviewable: a brief, a running application, and clear acceptance checks.
